# SkillSync

A mobile app for doing one coding challenge a day and keeping a streak going. I built it entirely on my phone with Expo and React Native.

## Features

- A new challenge every day.
- Mark a challenge as done and get a little confetti.
- A weekly streak tracker.
- Tips on coding and on building a portfolio.
- Progress is saved on the device with AsyncStorage.
- A quick link to your portfolio from inside the app.

## Built with

React Native, Expo, AsyncStorage, Expo Vector Icons, the Animated API and linear gradients.

## Try it

Install Expo Go on your phone (iOS or Android), then open http://bit.ly/4nDCfvP.
